# Bazaro 2027 – Neustart

Diese Startfassung ist absichtlich extrem einfach und robust.

## Für den ersten GitHub-Upload
Lade ALLE Dateien dieses Ordners gemeinsam in ein neues, leeres Repository hoch:

- `index.html`
- `bazaro-start.jpg`
- `.nojekyll`
- `README.md`

Danach GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

Das Bild ist in dieser ersten Online-Fassung absichtlich direkt und eindeutig als
`bazaro-start.jpg` eingebunden. Damit testen wir zuerst nur, dass die öffentliche
Countdown-Seite zuverlässig online funktioniert.

Erst NACH diesem erfolgreichen Test ergänzen wir die komfortable Mehrbild-Auswahl.
So vermischen wir die Ersteinrichtung nicht wieder mit der GitHub-Schreiblogik.
